===============================
How to use this test suite
===============================
To run these tests, execute the following command in your terminal:
python3 -m doctest -v tests/7-base_geometry.txt

===============================
Setup and Imports
===============================
First, import the BaseGeometry class from the module:

    >>> BaseGeometry = __import__('7-base_geometry').BaseGeometry
    >>> bg = BaseGeometry()

===============================
Testing area() Method
===============================
The area method should always raise an Exception because it is not implemented yet:

    >>> bg.area()
    Traceback (most recent call last):
        ...
    Exception: area() is not implemented

===============================
Testing Valid Integer Inputs
===============================
The integer_validator method should execute silently (return None) when valid integers are passed:

    >>> bg.integer_validator("width", 10)
    >>> bg.integer_validator("height", 89)
    >>> bg.integer_validator("size", 1)

===============================
Testing Non-Integer Inputs (TypeError)
===============================
If the value passed is not a strict integer, it must raise a TypeError:

    >>> bg.integer_validator("age", "John")
    Traceback (most recent call last):
        ...
    TypeError: age must be an integer

    >>> bg.integer_validator("weight", 75.5)
    Traceback (most recent call last):
        ...
    TypeError: weight must be an integer

    >>> bg.integer_validator("items", [1, 2, 3])
    Traceback (most recent call last):
        ...
    TypeError: items must be an integer

    >>> bg.integer_validator("properties", {"key": "value"})
    Traceback (most recent call last):
        ...
    TypeError: properties must be an integer

    >>> bg.integer_validator("status", None)
    Traceback (which call last):
        ...

Booleans inherit from integers in Python, but type() strict-checking catches them:

    >>> bg.integer_validator("is_active", True)
    Traceback (most recent call last):
        ...
    TypeError: is_active must be an integer

Testing sets and tuples as value parameters:

    >>> bg.integer_validator("age", {3, 4})
    Traceback (most recent call last):
        ...

    >>> bg.integer_validator("age", (4,))
